# 内置演练页面 + 交互录制器

一个零依赖（浏览器端）的内置演练页面，包含**表单、标签页、弹窗、滚动区域**，以及一个
**只在该页面工作**的交互录制器。录制器捕获点击、输入、聚焦、滚动，目标一律使用稳定
元素 ID；每一步都保存**执行前条件**与**执行后可观察状态摘要**，并在回放时逐步核对。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 演练页面：标签页、表单（含密码框）、可重建弹窗、滚动区域、录制器挂载点 |
| `app.js` | 演练应用：标签页切换、表单、弹窗（每次打开/重建都销毁并重建内部 DOM）、迟到的异步关闭演示 |
| `recorder.js` | 交互录制器（UMD）：录制、持久化、逐步回放、分歧定位 |
| `style.css` | 页面与录制器浮层样式 |
| `test/run.js` | jsdom 自动化测试（18 个用例） |
| `test/helpers.js` | 测试环境装配与交互模拟 |

## 使用

直接用浏览器打开 `index.html`（或用任意静态服务器），页面底部即录制器浮层：

- **开始录制** → 操作页面（点击、输入、聚焦、滚动）→ **停止录制**
- **回放**：先把演练应用重置回初始状态，再逐步执行；任一步失败立即停在第一处
- **清除轨迹**：删除持久化轨迹
- 轨迹保存在 `localStorage`（键 `walkthrough.recorder.trace.v1`），可**跨刷新保存**

## 录制格式（每一步）

```jsonc
{
  "seq": 1,
  "kind": "click | input | focus | scroll",
  "target": "f-name",                 // 稳定元素 ID（无 ID 的元素不会被录制）
  "pre":  {                           // 执行前条件
    "global": { "activeId": "...", "panel-profile": true, "modalOpen": false, "bump": "0" },
    "el":     { "tag": "INPUT", "type": "text", "value": "" }
  },
  "post": {                           // 执行后可观察状态摘要
    "global": { ... },
    "el":     { "tag": "INPUT", "type": "text", "value": "Alice" }
  }
}
```

- 滚动步骤的 `el` 摘要为 `{ "scrollTop": n }`，滚动事件做 16ms 合并；停止录制时
  尚未结算的滚动会立即落盘。
- **密码输入永不落盘字符**：`el` 摘要只有
  `{ "secret": true, "empty": false, "changed": true }`，只表达“已改变”。
  回放时也不使用真实密码，只重放“已改变”这一可观察结果。

## 回放失败语义

每一步依次执行四类检查，任一不符即**停在第一处**：

1. 目标元素是否仍存在（`missing`）
2. 执行前条件：目标元素摘要（`pre-element`）与全局状态（`pre-global`）
3. 执行动作
4. 执行后摘要：目标元素（`post-element`）与全局状态（`post-global`）

失败时录制器展示：

- 停在第几步、失败类型、分歧的**精确定位路径**（如 `el.value`、`global.panel-security`）
- **录制值** vs **当前值**（左右 JSON 对照）
- 后续步骤全部标记为 `blocked`，**不会继续执行**，因此不会产生“看似成功”的后续步骤

## 迟到的异步界面更新

录制器为每次“开始录制 / 开始回放 / 停止回放”分配递增的会话代号 `epoch`：

- 停止录制后，迟到的滚动、微任务回调不会写入旧轨迹；
- 开始新录制后，旧代号下挂起的回调一律作废；
- 停止回放后，挂起的后续步骤链与迟到的异步核对都不会继续，也不可能产生后续副作用。

页面里的“安排 120ms 后异步关闭弹窗”按钮专门用于演示这一点。
